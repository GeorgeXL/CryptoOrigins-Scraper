# Archived one-off scripts

This folder contains historical maintenance, migration, retag, list, dry-run, and test scripts that are not referenced by `package.json`.

Run from the repo root, for example:

```bash
npx tsx server/scripts/archive/retag-bitcoin-adoption.ts
```

These scripts were archived during the tag-manager cleanup to keep `server/scripts/` uncluttered while preserving operational history.
